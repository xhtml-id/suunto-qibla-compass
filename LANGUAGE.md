# Language Selection

## Primary language

English (`en`) is the primary and fallback language for Qibla Compass.

## Optional language

Bahasa Indonesia (`id`) remains available as an optional localization.

When installing a prebuilt file from the `build` folder:

- Choose a file ending in `-en.fea` for the default English interface.
- Choose the corresponding file ending in `-id.fea` for Bahasa Indonesia.

The display code before the language suffix must match the watch. Using **Build and Add App to Watch** in SuuntoPlus Editor is recommended because it identifies the compatible display package automatically.
